# Portfólio — Pedro Victor Guimarães

Site pessoal publicado em [peuvictor.github.io](https://peuvictor.github.io/). Apresenta projetos em Ruby on Rails, Java/Spring Boot, React e automações com IA.

## Conteúdo

- 13 projetos organizados por tecnologia, com filtros acessíveis.
- Capturas de tela de BH Agendamentos, GitHub Wiki e Sudoku carregadas diretamente dos respectivos repositórios no GitHub.
- Capturas de Alter Snack e FutWear mantidas em `imagens/` neste repositório.
- Layout responsivo, navegação móvel e respeito à preferência por movimento reduzido.

## Desenvolvimento

Página estática em HTML, CSS e JavaScript, sem etapa de build. Abra `index.html` no navegador ou sirva a pasta localmente, por exemplo:

```bash
python3 -m http.server 8000
```

Acesse `http://localhost:8000`. O GitHub Pages publica a branch `main`.
